# Profile Photo

Place your main profile picture here:
- **File Name:** `profile.jpg`
- **Recommended dimensions:** 1000x1200 or 1:1 square / 4:5 portrait
- **Format:** JPG, PNG, or WEBP

> Note: If this file is missing, Cineverse automatically renders a high-end procedural director silhouette placeholder so the portfolio never looks broken.
